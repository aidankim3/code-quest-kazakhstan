# Code Quest: Pac-Man Coding Adventure

카자흐스탄 국제학교 초등학교 5학년 학생을 위한 오프라인 IT 교육 게임입니다. 학생들은 선생님과 함께 짧은 코드를 직접 입력하거나 보기에서 답을 선택하면서 변수, 조건문, 충돌 처리, 유령 AI, FSM과 BFS 경로 탐색을 배웁니다. 정답을 맞히면 오른쪽 게임 화면에 결과가 바로 반영됩니다.

## 주요 특징

- 인터넷과 계정 없이 실행되는 HTML·CSS·JavaScript 수업 자료
- 카자흐어·영어 화면 지원
- 직접 타이핑과 보기 선택 방식 제공
- 총 4차시, 38개 미션, 최대 별 114개
- 팩맨과 고스트의 부드러운 이동 애니메이션
- 서로 다른 여러 미로
- 3마리 고스트와 PATROL·CHASE·FRIGHTENED FSM
- BFS 기반 고스트 경로 탐색
- 팩맨 효과음과 파워 닷
- 게임 일시정지, 재시작, 전체 화면 초기화
- 브라우저에 자동 저장되는 학생별 진도
- 빠른 학생의 선행을 막는 교사용 진도 잠금

## 폴더 구성

```text
초5 IT 수업/
├─ 학생 배포용/          학생 컴퓨터에 전달하는 실행 파일
│  ├─ index.html         학생용 게임 시작 파일
│  ├─ app.js             게임과 수업 동작
│  ├─ data.js            학생용 미션 데이터
│  ├─ styles.css         학생용 화면 디자인
│  ├─ 로컬서버_실행.bat  파일 직접 실행이 제한될 때 사용
│  └─ 학생_사용안내.txt
├─ 교사용/               학생에게 배포하지 않는 자료
│  ├─ teacher.html       정답·도움말·교사 메모 대시보드
│  ├─ course-data.js     교사용 전체 미션 데이터
│  ├─ 수업_운영안.md     4차시 상세 수업 운영안
│  └─ README.md          교사용 안내
├─ 배포_안내.md
└─ README.md
```

## 실행 방법

### 학생용

1. `학생 배포용` 폴더 전체를 학생 컴퓨터에 복사합니다.
2. Chrome 또는 Edge에서 `학생 배포용/index.html`을 엽니다.
3. 언어를 선택한 뒤 선생님과 함께 미션을 진행합니다.

대부분의 컴퓨터에서는 `index.html`을 두 번 클릭하면 바로 실행됩니다. 브라우저의 로컬 파일 제한으로 실행되지 않을 때는 `로컬서버_실행.bat`을 실행한 다음 자동으로 열린 페이지를 사용합니다.

### 교사용

1. Chrome 또는 Edge에서 `교사용/teacher.html`을 엽니다.
2. 차시 탭을 선택해 정답, 완성 코드, 도움말과 수업 메모를 확인합니다.
3. 필요하면 `모든 정답 펼치기` 또는 `수업안 인쇄`를 사용합니다.

## 수업 구성

| 차시 | 학습 주제 | 미션 수 | 수업 결과 |
|---|---|---:|---|
| 1차시 | 변수, 방향, `if` 조건문 | 10 | 팩맨 네 방향 이동 완성 |
| 2차시 | 화면 경계, 벽, 점수와 파워 아이템 | 10 | 플레이 가능한 미로 완성 |
| 3차시 | 고스트, 충돌, 생명과 최종 규칙 | 10 | 개인 게임 완성 및 플레이 |
| 4차시 | FSM 상태 전환과 BFS 경로 탐색 | 8 | 고스트 AI의 판단과 탐색 이해 |

각 차시는 50분 수업 두 번과 중간 10분 휴식에 맞춰 구성되어 있습니다. 학생 화면에는 수업 시간이나 교시를 표시하지 않고 `Session 1–4`와 `Challenge` 중심으로 보여 줍니다.

## 진도 잠금

각 차시는 전반과 후반으로 나뉩니다. 전반을 마친 뒤 후반으로 넘어갈 때와 다음 차시로 넘어갈 때 교사 잠금 창이 표시됩니다.

- 교사용 3자리 비밀번호: `530`
- 총 잠금 경계: 7개
- 비밀번호는 학생에게 알려 주거나 칠판에 적지 않고 교사가 직접 입력합니다.
- 학생에게는 반드시 `학생 배포용` 폴더만 전달합니다.

잠금 기능은 학생들의 수업 진도를 맞추기 위한 오프라인 장치입니다. 별도 서버 인증이 아니므로 개발자 도구를 이용한 전문적인 분석까지 막는 보안 기능은 아닙니다.

## 게임 조작

- 이동: 키보드 방향키 또는 `W`, `A`, `S`, `D`
- 시작: 게임 화면의 Play 버튼
- 일시정지·계속하기: Pause/Resume 버튼
- 게임 처음부터: Restart 버튼
- 현재 페이지 상태 초기화: Reset 버튼
- 미션 진행: 답 입력 또는 보기 선택 후 Run
- 다음 문제: 정답 처리 후 Next Mission

입력창에 코드를 작성하는 동안에는 방향키가 커서 이동에 사용되며 팩맨이 움직이지 않습니다.

## 게임 AI

고스트는 상황에 따라 다음 상태를 바꿉니다.

- `PATROL`: 미로를 순찰합니다.
- `CHASE`: 팩맨이 일정 거리 안에 들어오면 추적합니다.
- `FRIGHTENED`: 팩맨이 파워 닷을 먹으면 도망갑니다.

추적 상태에서는 BFS 탐색으로 벽을 통과하지 않는 최단 경로를 계산합니다. 고스트마다 목표 선택 방식이 조금씩 달라 움직임이 완전히 같지 않습니다.

## 진도 저장과 초기화

완료한 미션, 획득한 별과 통과한 잠금은 브라우저 `localStorage`에 저장됩니다. 같은 컴퓨터와 같은 브라우저로 다시 열면 이어서 진행할 수 있습니다.

게임의 Restart 또는 Reset 버튼은 저장된 전체 학습 진도를 삭제하지 않습니다. 진도를 완전히 지우려면 브라우저의 해당 파일·사이트 데이터를 삭제하거나 새 브라우저 프로필을 사용합니다.

## 배포 시 주의사항

- 학생에게는 `학생 배포용` 폴더만 복사합니다.
- `교사용` 폴더와 프로젝트 최상위 README는 교사가 보관합니다.
- 파일 이름과 폴더 구조를 바꾸면 HTML이 JavaScript나 CSS를 찾지 못할 수 있습니다.
- USB로 전달할 때도 학생용 폴더 안의 파일을 모두 함께 복사합니다.
- 카자흐어 문구는 실제 수업 전에 현지 교사와 한 번 더 확인하는 것을 권장합니다.

## 문제 해결

### 화면이 열리지만 게임이 보이지 않을 때

학생용 폴더 안에 `index.html`, `app.js`, `data.js`, `styles.css`가 모두 있는지 확인하고 Chrome 또는 Edge에서 다시 엽니다.

### 파일을 직접 열었을 때 동작하지 않을 때

`학생 배포용/로컬서버_실행.bat`을 실행합니다. Windows 보안 창이 나오면 개인 네트워크에서만 허용합니다.

### 소리가 나지 않을 때

브라우저는 사용자가 화면을 클릭하기 전까지 소리를 차단할 수 있습니다. Play 버튼을 누른 뒤 다시 확인하고 컴퓨터 음량도 확인합니다.

### 팩맨이 움직이지 않을 때

게임이 Pause 상태인지, 게임 종료 창이 열려 있는지, 코드 입력창에 커서가 있는지 확인합니다. 코드 입력을 마친 뒤 게임 화면을 클릭하고 방향키를 누릅니다.

### 다음 미션으로 넘어가지 않을 때

현재 답이 정답 처리되었는지 확인합니다. 차시 전반 또는 후반 경계라면 교사가 잠금 창에 `530`을 입력해야 합니다.

## 권장 환경

- 권장 화면 크기: 1280×720 이상
- 키보드 사용이 가능한 Windows 노트북 또는 데스크톱
- 인터넷 연결 불필요
